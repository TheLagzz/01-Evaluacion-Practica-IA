# 01-Evaluación-Práctica-IA
Desarrollar una aplicación interactiva que permita visualizar y comparar algoritmos de búsqueda aplicados a cuatro tipos de problemas: Búsqueda no informada, Búsqueda informada, Búsqueda local y Búsqueda adversaria.


Para inicializar la página debes usar el siguiente comando en la terminal:
python -m streamlit run app.py
